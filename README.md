# TaskFlow 📝

A modern and responsive task management web app designed to help users organize, prioritize, and track their daily tasks efficiently.

## 🚀 Live Demo

[Open TaskFlow](https://taskflow-pakeeza.vercel.app/)

## ✨ Features

- ✅ Add, complete, and delete tasks
- 🔍 Search tasks
- 🎯 Filter and sort tasks
- 🚨 Task priority management
- 📅 Due dates
- 🏷️ Task categories
- 📊 Productivity progress tracking
- 🌙 Dark and light mode
- 📱 Fully responsive design
- 🔔 Browser notifications
- ⏰ Automatic due-date reminders
- 📲 Progressive Web App (PWA) support
- 💾 Local storage for task data
